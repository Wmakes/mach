# mach.lang.target.extension.x64

## val SSSE3

```mach
pub val SSSE3: u64 = 0x1
```

the x86_64 extensions the code generator emits against, over the SSE2 baseline,
each a row of masc's x86 catalog, which names it, says what it implies and
publishes the x86-64-v2, v3 and v4 levels over it. a row nothing encodes against
yet is still a declared, probed requirement
